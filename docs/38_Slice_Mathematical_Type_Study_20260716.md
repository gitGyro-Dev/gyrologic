# Slice Mathematical Type Study v0

## 1. Purpose

This document begins Priority S-2: examination of the mathematical type of **Slice**.

The invariant Core remains unchanged:

```text
Structure
↓
Slice
↓
Stability
```

The primary definition remains:

```text
Slice is the process by which a path is opened
through a Structure toward an establishment.
```

Japanese:

```text
Sliceとは、Structureの中に、
一つの成立へ向かう道筋が開かれる過程である。
```

This study does not adopt a final mathematical object.

It compares several candidates while preserving the distinction that Slice is not mere extraction, filtering, selection, division, observation, or change.

---

## 2. Analysis Does Not Take in the Whole Object

Scientific inquiry, analysis, recognition, and measurement do not normally contain the whole target exactly as it is.

They operate through:

```text
questions
scales
relations
measurements
representations
boundaries
models
criteria
```

Therefore:

```text
analysis of X
≠
complete inclusion of X
```

However, this does not immediately imply:

```text
analysis
=
subtraction from X
```

or:

```text
analysis
=
removal of irrelevant parts
```

A target may remain unchanged while one relation, distinction, scale, or path becomes readable.

This distinction is central to Slice.

---

## 3. Why Extraction Is Insufficient

Extraction suggests:

```text
there is already a determinate part inside the whole
and that part is removed or copied out
```

Slice may sometimes include extraction, for example:

```text
extracting a field from a record
sampling a material
retrieving one interval from a log
```

But Slice is broader.

A Slice may make readable:

```text
a relation not previously explicit
a Difference produced through comparison
a Boundary generated through localization
a continuity across separated events
a path that was not represented as one object beforehand
```

Therefore:

```text
extraction
may implement a Slice

but

Slice
≠
extraction
```

---

## 4. Why Thinning or Subsampling Is Insufficient

Thinning, subsampling, or decimation suggests reducing the number of elements.

```text
X
→
X' ⊂ X
```

This is useful when Slice concerns:

```text
sampling
resolution reduction
representative selection
computational compression
```

However, a Gyro Slice may increase the number of readable relations even when fewer elements are directly examined.

For example:

```text
one authentication event
may open relations to prior device, time, motion, and attack traces
```

Thus:

```text
less directly observed content
may produce more readable relational depth
```

Therefore:

```text
Slice
≠
merely making the target smaller
```

---

## 5. Why Filtering and Sieving Are Insufficient

Filtering or sieving suggests:

```text
input
→ filter condition
→ retained elements + rejected elements
```

This is a strong candidate for some implementations.

It captures:

```text
admissibility
exclusion
noise reduction
criteria-based passage
```

But it also introduces risks.

### 5.1 Pre-existing-element assumption

Filtering normally assumes that the relevant elements already exist as separately identifiable inputs.

Slice may instead open a relation or distinction that was not previously represented as an element.

### 5.2 Removal assumption

Filtering suggests that non-passing elements are removed.

In Gyro Logic:

```text
not currently foregrounded
≠
deleted
```

and:

```text
not readable under this Slice
≠
nonexistent
```

### 5.3 Binary-passage assumption

A filter often suggests pass/fail.

Slice may involve:

```text
partial readability
multiple relations
re-Slice
ambiguity
Difference
Boundary formation
```

Therefore:

```text
filtering
may be one Slice mechanism

but

Slice
≠
filtering in general
```

---

## 6. Why Selection Is Insufficient

Selection suggests choosing one item or subset from already available alternatives.

```text
Select : P(X) → P(X)
```

Selection is relevant because Slice is directional and does not exhaust Structure.

However, a pure selection model assumes:

```text
all alternatives are already individuated
all relevant candidates are already available
Slice only chooses among them
```

This conflicts with the current interpretation of Structure as:

```text
not-yet
not globally closed
not exhausted by a pre-enumerated possibility list
```

A Slice may not merely select a completed possibility.

It may make one possible establishment path distinguishable for the first time.

Therefore:

```text
selection
may occur within Slice

but

Slice
≠
selection from a finished list
```

---

## 7. Why Division or Partition Is Insufficient

Division and partition suggest separating a whole into disjoint parts.

```text
X = A_1 ⊔ A_2 ⊔ ... ⊔ A_n
```

This captures some physical and analytical cases:

```text
cutting a cake
segmenting an image
partitioning a dataset
classifying a population
```

But Slice does not always produce disjoint parts.

A single element may participate in multiple valid Slices.

```text
one event
may belong to temporal, behavioral, security, and causal readings
```

Relations may overlap, and one Slice need not account for the complement of another.

Therefore:

```text
Slice result
+
remainder
≠
necessarily the whole Structure
```

and:

```text
Slice
≠
partition in general
```

---

## 8. Candidate: Localization

Localization is currently one of the stronger mathematical analogies.

It suggests:

```text
restrict attention to a region, scale, relation, or neighbourhood
without claiming to exhaust the whole object
```

Advantages:

```text
local rather than global establishment
no necessary deletion of the rest
multiple overlapping localizations
compatibility with Context and Orientation
possible later gluing or comparison
```

Risks:

```text
localization may sound spatial only
it may assume the local region is already defined
it may describe where Slice operates but not how a path opens
```

Thus:

```text
localization
is strongly relevant
but may describe only one aspect of Slice
```

---

## 9. Candidate: Relation Formation or Articulation

Slice may cause one relation or distinction to become explicit or usable.

A provisional image is:

```text
implicit or unreadable relational field
↓ Slice
one articulated relation or path
```

`articulation` here means that something becomes differentiated and connected enough to be followed.

Advantages:

```text
does not require removal
can create readable distinctions
supports relational rather than object-only analysis
fits Boundary and Difference formation
```

Risks:

```text
may sound purely linguistic or epistemic
may overstate that Slice creates the underlying relation
may underrepresent physical or operational Slice
```

Therefore, a safer statement is:

```text
Slice may articulate a relation
without necessarily creating everything that relation depends on
```

---

## 10. Candidate: Partial Relation

A total function:

```text
f : S → P
```

is currently too strong because it suggests:

```text
one defined output for every input
completed transformation
no unreadable region
```

A partial relation is safer:

```text
Σ_{B,c} ⊆ S × P
```

or:

```text
Σ_{B,c} : S ⇝ P
```

where:

```text
B = Operator Orientation
c = Context
P = opened path or Slice-relative articulation
```

This permits:

```text
one-to-many relations
partial definition
failed or incomplete Slice
multiple possible paths
Context dependence
```

However, a relation usually records which pairs are connected.

It may not by itself preserve:

```text
slice-ing as process
how the path opens
intermediate differentiation
act-like movement from not-yet
```

Therefore:

```text
partial relation
may model Slice admissibility or slice-done
but may not fully model Slice as process
```

---

## 11. Candidate: Morphism or Arrow

A morphism expresses a directed transformation or relation between mathematical objects.

```text
S \xrightarrow{\Sigma} P
```

Advantages:

```text
direction
composition
relation between stages
compatibility with repeated Core realizations
```

Risks:

```text
morphisms are often identified by source and target behaviour
internal slice-ing may disappear
source and target object types must be fixed prematurely
composition may appear more rigid than Gyro relations permit
```

Thus, morphism language may become useful later, especially for compositional models, but is not yet sufficient as the primary meaning of Slice.

---

## 12. Candidate: Constraint Propagation

Constraint propagation narrows admissible values or relations by applying constraints repeatedly.

It captures:

```text
progressive narrowing
interaction among conditions
partial determination
local-to-relational effects
```

This resembles the movement from:

```text
local not-yet
→
local determination
```

However, it may be too restrictive because:

```text
Slice may reveal rather than only narrow
Slice may expand readable relations
constraints may arise during Slice
not all Slices are problem-solving procedures
```

Therefore:

```text
constraint propagation
may describe one computational form of Slice
but not Slice in general
```

---

## 13. Candidate: Selective Opening

`Selective Opening` is currently the closest conceptual phrase, but it is not yet a standard mathematical object.

It combines:

```text
selective
=
not every relation or direction is equally activated
```

and:

```text
opening
=
a path becomes available or distinguishable toward establishment
```

Its advantages are:

```text
no necessary subtraction
no assumption of a completed possibility list
no requirement that the target be physically divided
compatibility with local determination without global closure
compatibility with overlapping and repeated Slices
```

Its risks are:

```text
not yet mathematically defined
may hide the process under a metaphor
selective may still imply pre-existing alternatives
opening requires a formal account of path and accessibility
```

Therefore, `Selective Opening` is currently best treated as a Gyro characterization that later mathematical objects must implement or approximate.

---

## 14. Stronger Integrated Image

The current strongest interpretation is not one candidate alone.

It is a combination of:

```text
Orientation-relative localization
+
partial relational articulation
+
path-opening process
```

A provisional expression is:

```text
Σ_{B,c} : S ⇝ P
```

with the intended meaning:

```text
under Orientation B and Context c,
Slice locally articulates and opens one path P through Structure S
toward an establishment,
without subtracting P from S or globally closing S
```

This notation is not a final definition.

---

## 15. Slice Does Not Consume Structure

The present discussion produces an important principle:

```text
Slice does not normally consume, subtract, or exhaust Structure.
```

Therefore, in general:

```text
S - Slice(S)
```

should not be assumed to represent a meaningful `background` or remainder.

Likewise:

```text
S = Slice(S) + remainder
```

is not generally valid.

A Slice may change the target through an associated operation, but the logical function of Slice is path-opening, not subtraction.

---

## 16. Slice and Act

Prior discussion distinguished pre-Slice foregroundability from Slice:

```text
foregroundability
=
a direction appears slightly visible while remaining near not-yet
```

```text
Slice
=
a path actually begins to open in that direction
```

Thus Slice has an act-like character.

However:

```text
Slice
≠
any action
```

The minimal act-like property is:

```text
there is a transition from merely possible directional readability
to an actual path-opening process
```

This does not require physical action, conscious decision, or external intervention.

## 17. Failure Cases

### 17.1 Subtraction Collapse

```text
Slice = remove one part from Structure
```

This loses overlapping relations and non-consuming readability.

### 17.2 Completed-list Collapse

```text
Slice = select one item from all pre-existing possibilities
```

This contradicts not-yet and emergent path readability.

### 17.3 Filter Collapse

```text
Slice = pass/fail filtering
```

This loses relation formation, partial readability, and Re-Slice.

### 17.4 Partition Collapse

```text
Slice = disjoint decomposition of Structure
```

This excludes overlapping Slices and relational depth.

### 17.5 Observation Collapse

```text
Slice = passive observation
```

This loses the act-like opening from not-yet.

### 17.6 Operation Collapse

```text
Slice = any act or transformation
```

This confuses Structure change with path-opening.

### 17.7 Total-function Collapse

```text
Slice = total deterministic map
```

This excludes partiality, ambiguity, failure, and multiple paths.

---

## 18. Current Working Position

The present working position is:

```text
Slice is not best represented as extraction, filtering,
thinning, selection, or partition alone.

Each may describe one implementation or property of Slice.

The stronger common structure is:

Orientation-relative localization
+
partial relational articulation
+
an act-like process that opens one establishment path
without subtracting from or globally closing Structure.
```

Japanese:

```text
Sliceとは、Structureから一部を差し引くことではない。

あるOrientationとContextのもとで、
Structureの一部の関係・区別・範囲を局所的に明瞭化し、
一つの成立へ向かう道筋を実際に開き始める過程である。

その道筋はStructureから除去されず、
Structure全体も閉じられない。
```

This is a study characterization, not a replacement Core definition.
