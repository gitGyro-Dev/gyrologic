# Slice as Provisional Becoming Study v0

## 1. Purpose

This document refines the mathematical study of Slice after identifying a problem in the following question:

```text
Does Slice discover a path?
Does Slice generate a path?
Does Slice make a path available?
```

The invariant Core remains unchanged:

```text
Structure
↓
Slice
↓
Stability
```

The primary Slice definition remains:

```text
Slice is the process by which a path is opened
through a Structure toward an establishment.
```

This document does not replace that definition.

It clarifies the meaning of `a path is opened`.

---

## 2. Why the Previous Three-way Question Is Misleading

The verbs:

```text
discover
generate
make available
```

all tend to assume that:

```text
path
```

is an object distinguishable from Slice, and that Slice then performs some operation on it.

This introduces premature alternatives:

```text
the path already existed and was found
```

or:

```text
the path did not exist and was created
```

or:

```text
the path existed but was unusable
```

Gyro Logic may not need to decide among these alternatives at the Core level.

The safer position is:

```text
through Slice,
one local way in which Structure has become
appears or is articulated.
```

Thus the focus shifts from the ontological status of the path before Slice to what becomes locally available through the Slice process.

---

## 3. The Basic Intuition: “こうなった”

The present intuition is:

```text
Sliceしたら、こうなった。
```

This does not mean:

```text
Slice selected a completed answer.
```

It means that, through Slice, one local configuration, distinction, relation, or course has taken form.

A provisional English image is:

```text
through Slice, it has locally become this way
```

or:

```text
Slice yields a local articulation of how it has become
```

Neither expression is adopted as a definition.

---

## 4. “こうなった” Is Not Completion

The phrase:

```text
こうなった
```

may sound completed, but the intended meaning is not final completion.

It is closer to:

```text
こうなっている。
このように現れている。
では、これはどう読まれるのか。
```

Therefore:

```text
slice-done
≠
final completion
```

```text
slice-done
≠
Stability
```

```text
slice-done
≠
Operator approval
```

The Slice process has locally articulated something, but whether that articulation becomes readable as an establishment that can continue belongs to Stability.

---

## 5. Slice and Stability

The distinction may be expressed as:

```text
Slice
=
local becoming or articulation
```

```text
Stability
=
that opened articulation becomes readable
as an establishment that can continue
```

Japanese image:

```text
Slice
=
局所的に「こうなった」が現れる過程
```

```text
Stability
=
その「こうなった」が、
継続可能な成立として読める状態
```

The word `becoming` is provisional and must not collapse Slice into all change.

```text
change
≠
Slice
```

Only a change or articulation that opens one local course toward establishment belongs to Slice.

---

## 6. “こうなった。どう？”

A useful conversational image is:

```text
こうなった。
どう？
```

This should not be interpreted anthropomorphically as Slice asking a question.

Rather, it expresses an unresolved theoretical position:

```text
one local articulation has appeared
but its continuing establishment is not yet guaranteed
```

Thus:

```text
こうなった
=
local articulation
```

```text
どう？
=
its relation to Stability and later Response remains open
```

This preserves the distinction:

```text
Slice is not an evaluator.
Stability is not an evaluator.
Operator Response reacts after Stability.
```

---

## 7. Relation to Not-Yet

Structure has been provisionally interpreted as:

```text
未
not-yet
not globally closed
```

Before Slice:

```text
a local course is not yet articulated
```

Through Slice:

```text
one local articulation appears
```

But:

```text
local articulation
≠
global determination
```

Therefore:

```text
Structure remains globally not-yet
while Slice produces a local “this is how it has become”
```

This is compatible with:

```text
local determination without global closure
```

but the word `determination` should remain weaker than final truth or irreversible fixation.

---

## 8. Mathematical Consequences

The current notation:

```text
Σ_{B,c} : S ⇝ P
```

may still be useful, but `P` should not be interpreted too quickly as a pre-existing path object.

A safer reading is:

```text
P
=
the locally articulated course or configuration
that appears through Slice
```

A more explicit provisional schema is:

```text
Σ_{B,c}(S) ⇝ a
```

where:

```text
a
=
a local articulation produced through Slice
```

However, ordinary function notation remains risky because:

```text
Slice may be ongoing
Slice may be partial
Slice may be interrupted
multiple articulations may remain possible
its result may depend on recursive interaction
```

Therefore no final notation is adopted.

---

## 9. Comparison with Existing Candidate Types

### 9.1 Map

A map may represent a completed association:

```text
S ↦ a
```

but may hide the process by which `a` becomes articulated.

### 9.2 Morphism

A morphism may represent transformation or composability, but may reduce Slice to its endpoints.

### 9.3 Relation

A relation can preserve one-to-many or partial correspondence, but may not express the active emergence of `こうなった`.

### 9.4 Constraint Propagation

Constraint propagation can explain how possibilities narrow or become compatible, but may overstate pre-existing formal constraints.

### 9.5 Selective Opening

Selective Opening remains useful as a characterization, provided that `selection` does not imply choosing from a completed list.

The current emphasis is:

```text
not selection of a result
but local articulation through which
one way of becoming appears
```

---

## 10. Failure Cases

### 10.1 Discovery Collapse

```text
Slice = finding a path that fully existed beforehand
```

This may erase the role of Slice in articulation.

### 10.2 Generation Collapse

```text
Slice = freely creating a path from nothing
```

This ignores Structure constraints and non-arbitrariness.

### 10.3 Availability Collapse

```text
Slice = switching a completed path from unavailable to available
```

This assumes too much about the path before Slice.

### 10.4 Completion Collapse

```text
こうなった = final answer
```

This collapses Slice into Stability or Response.

### 10.5 Change Collapse

```text
all becoming = Slice
```

This contradicts the established distinction:

```text
change ≠ Slice
```

---

## 11. Current Working Position

The current working position is:

```text
Slice should not yet be described primarily as
path discovery, path generation, or path activation.

Through Slice, one local articulation appears:

“こうなった。”

This articulation is not final completion.
It remains open to the question of whether it becomes readable
as an establishment that can continue.

That relation belongs to Stability.
```

Japanese summary:

```text
Sliceとは、あらかじめ存在する道筋を発見・選択することでも、
無から道筋を生成することでもない。

Sliceを通じて、Structureの中に、
局所的な「こうなった」が現れる。

ただし、それは完了でも確定でもなく、
継続可能な成立として読めるかどうかに開かれている。
```

## 12. Open Questions

1. Is `local articulation` a better mathematical primitive than `opened path`?
2. Does `こうなった` refer to a state, relation, configuration, section, or event?
3. Is slice-done best modeled as a boundary object between Slice and Stability?
4. Can one Slice yield several mutually incompatible local articulations?
5. How should interrupted Slice be represented before `こうなった` appears?
6. Does every local articulation preserve a trace in later Structure?
7. Can Stability fail even when a coherent local articulation has appeared?
8. How should this distinction be expressed without anthropomorphizing `どう？`?
