# Structure Ontological Type Study v0

## 1. Purpose

This document begins Priority S-1:

```text
What kind of mathematical object is Structure?
```

The invariant Core remains unchanged:

```text
Structure
↓
Slice
↓
Stability
```

The primary definition remains:

```text
Structure is the mode in which something can be established.
```

Japanese:

```text
Structureとは、何かが成立し得る様式である。
```

This study does not adopt a final mathematical object.

Its first purpose is to avoid collapsing Structure into one familiar category such as state space, object, relation, or state.

---

## 2. Initial Problem

The following candidates have been considered:

```text
state space
relational structure
constraint structure
possibility space
new mathematical object
```

However, each candidate emphasizes only one aspect.

```text
space
```

may suggest a container in which states already exist.

```text
relational structure
```

may suggest only relations among elements.

```text
constraint structure
```

may suggest only what is prohibited or permitted.

```text
possibility space
```

may suggest that all possibilities are already enumerated.

None of these immediately expresses the full Gyro intuition:

```text
Structure may be read as an object,
a current condition,
a relational organization,
and a mode of further establishment.
```

---

## 3. State Is Not Structure

A state is not generally identical to Structure.

```text
state
≠
Structure
```

A state usually means:

```text
how something currently is
```

Structure means:

```text
the mode in which something can be established
```

Therefore, a state may be one current section or configuration of Structure.

Provisionally:

```text
x_n ∈ State(S_n)
```

may represent a current state `x_n` readable within Structure `S_n`.

But:

```text
S_n
≠
x_n
```

Structure is not exhausted by one state.

---

## 4. Object Is Not Structure

An object may bear or instantiate Structure.

```text
object
≠
Structure
```

For example:

```text
a human body
an ocean
a document
a runtime
a society
```

may be treated as objects or entities under one Slice.

However, Gyro Structure concerns more than the material or nominal object.

It includes the mode under which relations, states, Boundaries, Differences, and further establishments may become possible or readable.

Therefore:

```text
object
may be a bearer of Structure
```

but:

```text
Structure
is not reducible to the bearer alone
```

---

## 5. Relational Structure Is Not Enough

Relations are likely essential.

A Structure may contain or support:

```text
material relations
functional relations
causal relations
semantic relations
spatial relations
institutional relations
continuity relations
```

However:

```text
Structure
≠
relation set alone
```

A relation set does not automatically express:

```text
current state
establishability
not-yet character
admissible Slice
incorporated readability
capacity for further transformation
```

Relations are probably components of Structure, not the complete mathematical type.

---

## 6. One Reality May Be Read in Multiple Modes

The same underlying reality may be read differently.

For example, an ocean may be read as:

```text
an object
```

under a geographical Slice;

```text
a state
```

under a climatic Slice;

```text
a relational system
```

under an ecological Slice;

```text
a process-supporting medium
```

under a hydrological Slice.

Likewise, a runtime may be read as:

```text
one process object
a current execution state
a relation among services
a continuity-bearing system
```

Thus:

```text
object-like
state-like
structure-like
process-supporting
```

may be Slice-relative readings of one Structure.

This does not mean that Operator creates Structure existence.

It means that different mathematical aspects may become readable under different Slices.

---

## 7. Operator Relativity Must Be Bounded

A tempting formulation is:

```text
Structure is object, state, or relation depending on Operator.
```

This is too strong.

It risks making Structure entirely observer-created.

A safer distinction is:

```text
Structure existence and capacity
≠
Operator-relative reading
```

Operator Orientation may influence:

```text
which aspect becomes relevant
which relation is foregroundable
which state is selected
which Boundary becomes readable
which establishment path is opened
```

But Operator does not freely determine what Structure is.

Therefore:

```text
Operator affects the mathematical presentation of Structure
without necessarily constituting Structure itself.
```

---

## 8. A Layered Mathematical Reading

A useful temporary separation is:

```text
Bearer
=
what carries or instantiates the Structure
```

```text
Organization
=
relations and constraints within the Structure
```

```text
Current state
=
what is currently readable or instantiated
```

```text
Establishability
=
what further establishment paths may be opened
```

These are not Core elements.

They are analytical dimensions for testing candidate mathematical models.

A provisional schema is:

```text
S = (X, R, C, x, A)
```

where:

```text
X = bearer or carrier domain
R = relations
C = constraints or conditions
x = current state or configuration
A = establishability or admissible opening capacity
```

This is not a definition.

It is only a diagnostic decomposition.

---

## 9. Why a State Space Alone Is Insufficient

A conventional state space usually provides:

```text
possible states X
current state x ∈ X
transition rule
```

This is useful but may be insufficient because Gyro Structure also requires:

```text
not-yet without complete enumeration
Slice-relative readability
incorporated readability
changing relations and constraints
local establishment without global closure
possible Jump and Void
```

A state space may still be used as one component or implementation model.

But:

```text
Structure
≠
state space by default
```

---

## 10. Why a Possibility Space Alone Is Insufficient

A possibility space suggests:

```text
all possible outcomes are already contained in a domain
```

That may conflict with the current Slice understanding.

Slice is not necessarily selection from a completed list of possibilities.

It may open a path that was not previously readable as an explicit option.

Therefore:

```text
possible establishment
≠
already enumerated possible state
```

Structure may support establishability without containing a complete catalog of future establishments.

---

## 11. Current Strongest Position

The current strongest position is:

```text
Structure should not yet be identified with one mathematical category.
```

It appears to require at least the capacity to support:

```text
a bearer or domain
relations
constraints or conditions
current state-like sections
not-yet establishability
multiple Slice-relative readings
retained readability effects
future transformation
```

A useful working phrase is:

```text
Structure is an establishability-bearing organized entity.
```

Japanese candidate:

```text
Structureは、成立可能性を担う組織化された存在である。
```

However, `entity` and `organized` may still be too object-like or too fixed.

This phrase is not adopted as a definition.
