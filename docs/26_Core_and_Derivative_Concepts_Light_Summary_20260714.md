# Gyro Logic Core and Derivative Concepts — Light Summary

## 1. Structure

Primary definition:

```text
Structure is the mode in which something can be established.
```

```text
Structureとは、何かが成立し得る様式である。
```

Current image:

```text
未
not-yet
not globally closed
```

Structure already exists, but is not exhausted by one readable establishment.

It may change, retain prior traces, and remain open to further establishment.

```text
Structure
≠
Slice result
≠
Trajectory
≠
Operator-relative representation
```

---

## 2. Slice

Primary definition:

```text
Slice is the process by which a path is opened
through a Structure toward an establishment.
```

```text
Sliceとは、Structureの中に、
一つの成立へ向かう道筋が開かれる過程である。
```

Current image:

```text
local path opening
without global closure
```

Slice does not complete Structure.

It opens one direction, relation, range, or path toward establishment.

```text
change
≠
Slice
```

Change may be an object, condition, or consequence of Slice, but is not Slice itself.

---

## 3. Stability

Primary definition:

```text
Stability is the state in which an opened path becomes readable
as an establishment that can continue.
```

```text
Stabilityとは、開かれた道筋が、
一つの成立として継続可能な状態である。
```

Current image:

```text
こうなったと読める
そして、なお続き得る
```

Stability is a local settlement of one opened path.

```text
Stability
≠
ending
≠
no change
≠
Structure-wide closure
≠
score
≠
Operator decision
```

The remaining `not-yet` character of Structure is not eliminated.

---

## 4. Trajectory

Trajectory is a derivative concept, not a Core element.

Current image:

```text
Gyro realizations accumulate, overlap, and fold.

When their traces and relations are later followed
under a particular Orientation,
a trajectory becomes readable.
```

Japanese image:

```text
成立や変化が積み重なり、折り重なり、痕跡を残す。

それらをあるOrientationから辿ると、
軌跡として読める。
```

```text
Trajectory
≠
pre-existing road
≠
simple continuation
≠
history storage
≠
final result
```

It is interpretive, but not arbitrary.

---

## 5. Operator

Operator is a Gyro element, but not a Core element.

Current image:

```text
Operator
→ bears, provides, or updates Orientation and Response
```

```text
Operator Orientation
→ conditions how one Slice is directed
```

```text
Operator Response
→ reacts after Stability
```

Operator does not create Structure existence and does not directly determine Stability.

Its role is real but bounded.

```text
Operator
≠
Structure
≠
Slice
≠
Stability
```

---

## 6. Integrated Image

```text
Structure
=
未・閉じ切っていない成立様式

Operator Orientation
=
一つの方向を条件づける

Slice
=
その方向の下で一つの道筋が開かれる

Stability
=
その道筋が継続可能な成立として局所的に落ち着く

Trajectory
=
積み重なり折り重なった成立痕跡を、
あとから辿ることで読まれる軌跡
```

Core remains:

```text
Structure
↓
Slice
↓
Stability
```

Trajectory and Operator remain derivative or supporting concepts.
