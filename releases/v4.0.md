# Gyro Logic v4.0

## Overview

Gyro Logic v4.0 consolidates the substantial theoretical, formalization, publication, and repository-automation work completed after v3.0.

The invariant Core remains unchanged:

```text
Structure
↓
Slice
↓
Stability
```

This release does not replace or extend the Core. It refines the surrounding formal organization, clarifies derivative concepts, and publishes a substantial Minimal Formal Model as a new research artifact.

## Major changes

### 1. Core definition refinement

- Refined the formal descriptions of Structure, Slice, and Stability.
- Preserved the distinction between canonical definitions and provisional mathematical candidates.
- Clarified that Stability is a continuable establishment rather than an evaluator, terminal condition, or universal scalar.
- Maintained the separation among Gyro Unit, Gyro Process, and Gyro Loop.

### 2. Minimal Formal Model

Added a comprehensive bilingual Minimal Formal Model covering:

- Structure
- Slice process
- local articulation
- Stability Scene
- Incorporated Readability
- Continuity Readability
- contextual Trajectory
- Difference
- Boundary

The model is explicitly exploratory and does not claim a complete axiomatization or reduction of Gyro Logic to one established mathematical field.

### 3. Mathematical comparison

Compared the proposed schema with partial models from:

- relational structures
- graph and hypergraph theory
- topology
- dynamical systems
- transition systems
- event structures
- category theory
- proof theory
- constraint propagation
- probability and statistics
- sheaf-like structures
- process algebra

### 4. Boundary and Difference refinement

- Preserved Difference as a Slice-, Orientation-, and Context-relative structured relation.
- Distinguished Difference from distance, numerical error, and Boundary.
- Treated Boundary as a derivative readable distinction rather than a new Core element.
- Preserved Boundary State as a provisional relational classification.

### 5. Contextual Trajectory

- Distinguished Trajectory from chronological logs and predefined state sequences.
- Preserved the separation among relation existence, traceability, continuity readability, and Identity.
- Added support for branching, merging, gaps, retrospective reinterpretation, Re-Slice, and Jump.

### 6. Bilingual paper artifacts

Added and validated English and Japanese manuscript artifacts, including:

- assembled Markdown manuscripts
- rendered PDFs
- three formal overview figures
- bibliography integration
- consistency review output
- PDF figure validation output

The English manuscript was submitted to Jxiv as a preprint candidate.

### 7. Jxiv compliance work

- Added author, affiliation, ORCID, correspondence, funding, conflict-of-interest, data-availability, and code-availability declarations.
- Added bilingual disclosure of the use of generative AI and AI-assisted tools.
- Clarified the author's review, verification, editing, and full responsibility for the manuscript, theoretical claims, citations, references, and final text.

### 8. Reproducible paper build and validation

Added GitHub Actions and supporting tools to:

- assemble bilingual manuscripts
- render PDFs with Pandoc and LuaLaTeX
- validate fonts and figures
- detect caption duplication and figure-text overlap risks
- commit generated artifacts safely
- serialize concurrent paper-generation runs
- rebase and retry when the default branch advances during generation

## Layer consistency

The release preserves the project layers:

```text
Gyro Logic
↓
GyroOS
↓
GyroAuth
```

- Gyro Logic remains the theory layer.
- GyroOS implementation requirements do not redefine Gyro Logic.
- GyroAuth application requirements do not redefine Gyro Logic or GyroOS.
- Project Cycle and Developer Toolkit remain management and tooling layers outside the theory Core.
